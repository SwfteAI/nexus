Governance & enforcement

Every action is judged before it runs.

The agent proposes a tool call; Nexus decides — on the machine, synchronously, before execution. A network problem can't route around it, because the decision never leaves the loop.

→
ALLOW
Safe & in-bounds. Runs untouched; captured for the audit trail.
ASK
Needs a human. Developer confirms; the choice can be learned so it isn't asked twice.
DENY
Out of bounds. Blocked before it runs; reason shown to the developer, finding recorded.
ENFORCE

Deny outright. The guardrail is live — dangerous calls are stopped.

AUDIT

Record what would have been denied, but allow it — roll policy out with zero disruption first.

OFF

Capture only. Full traceability, no blocking.

Stops: destructive commands · out-of-bounds paths · secret exfiltration · unattended supply-chain installs
