How each one works

Compress the context

The context window is compressed in flight before it's sent — the signal is kept, the bulk isn't.

Filter tool output

A 5,000-line build log or ls -R is trimmed before it re-enters context. You never pay for noise.

Reuse prior searches

Everything the agent already searched, read, or derived is indexed and served back — re-discovery becomes a lookup.

Route by outcome

Proposes the cheapest model your repo's own results justify. Most turns don't need the flagship.

Codify repeats → 0 tokens

Recurring command sequences replay as scripts — no agent turn, no tokens at all.
