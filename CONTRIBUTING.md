# Contributing to Nexus

This repository is the **public home of the product** — README, docs, and the issue tracker. The
Nexus source is proprietary and not hosted here; the tool ships as a signed, compiled binary via
npm (`@swfte/nexus`) and PyPI (`swfte-nexus`).

The most valuable ways to help:

- **Report a bug** — include OS/arch, install method (`npm`/`pip`), `nexus doctor` output, and
  expected vs. actual behaviour.
- **Request a feature** — describe the problem, not just the feature.
- **Tell us how you use it** — governance, savings, other agents (Codex and more are coming).

For security, licensing, or interest in the upcoming self-hostable open-source stack, email
**sales@swfte.com** (security reports: see [SECURITY.md](SECURITY.md)). We can't take source-code
PRs here — there's no source to change — but issues genuinely shape the roadmap.
