# Security Policy

Nexus is a governance and enforcement tool for AI coding agents; we take its security seriously.

**Report a vulnerability privately** — do not open a public issue for security reports. Email
**sales@swfte.com** with details and steps to reproduce, and we will respond promptly and coordinate
disclosure. The compiled binaries are Developer ID signed and Apple-notarized (macOS) and shipped
only through npm (`@swfte/nexus`) and PyPI (`swfte-nexus`); verify you obtained yours from those
sources.
